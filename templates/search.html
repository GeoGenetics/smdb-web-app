📚 Download All SMDB Tables

Press the "Download all tables..." button below to download all raw database tables, including both old unstandardized CGG tables and new standardized field sample data.

Note: You might need to convert data to a common case to avoid case sensitivity issues if you cannot do case-insensitive filtering.

Use UTF-8 if in doubt


To download the same using curl, use the following command in your terminal: 
curl -L -o "all_SMDB_tables_curl_$(date +"%Y%m%d_%H%M%S").zip" -X POST -d 'encoding_type=utf_8' http://dandyweb01fl.unicph.domain:5100/download_all_individual_tables

Note: You might need to convert data to a common case to avoid case sensitivity issues if you cannot do case-insensitive filtering.

curl -L -o "all_binf_qc_tables_curl_$(date +"%Y%m%d_%H%M%S").zip" -X POST -d 'encoding_type=utf_8' http://dandyweb01fl.unicph.domain:5100/download_all_binfqc_tables

🔗 Download Joined Standardized SMDB Data (outer joined)

Select which databases you want to include in the download and then press the "Download joined data..." button below to download a zip file with the selected data included.

Note: You might need to convert data to a common case to avoid case sensitivity issues.


To download the same using curl, use the following command in your terminal: 
curl -L -o "SMDB_merged_curl_$(date +"%Y%m%d_%H%M%S").zip" -X POST -d 'checkbox_smdb=on' http://dandyweb01fl.unicph.domain:5100/download_merged_standardized

🌍 Download CGG Sediment/Water Spreadsheet

CGG Sediment/Water Spreadsheet is an old spreadsheet that contains non-standardized data and is therefore seperated from SMDB data. If you cant find your data in some of the other options above, this might be the place to look for it.

Note: You might need to convert data to a common case to avoid case sensitivity issues.


To download the same using curl, use the following command in your terminal: 
curl -L -o "cgg3_sheet_data_curl_$(date +"%Y%m%d_%H%M%S").csv" -X POST http://dandyweb01fl.unicph.domain:5100/download_cgg
